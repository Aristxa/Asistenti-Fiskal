# Runtime dependencies for the Hugging Face Space only.
#
# Deliberately smaller than the project's requirements.txt. The Space never
# crawls, never opens a PDF and never runs tests -- it loads a committed index
# and encodes one question per request. Shipping httpx, selectolax, pymupdf and
# pytest would only slow the boot.
#
# NOT listed here, on purpose:
#   gradio  -- the builder installs the version named by sdk_version in README.md
#   spaces  -- the builder installs it automatically for ZeroGPU hardware
# Pinning either one collides with the version the builder appends to its own
# pip install line, and the build fails.
#
# torch is pinned within the range ZeroGPU accepts (the builder adds
# "torch<=2.11.0"). The application asks for no GPU -- the corpus is embedded
# offline -- but the hardware requires a GPU-decorated entry point, and free CPU
# Gradio Spaces need a PRO subscription on this account.
